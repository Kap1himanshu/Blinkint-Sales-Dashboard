# 🛒 Blinkit Sales Performance & Outlet Analysis Dashboard

## 1. Project Title / Headline

Blinkit Sales Performance & Outlet Analysis Dashboard  

An interactive Power BI dashboard built to analyze Blinkit’s retail sales data — focusing on revenue performance, outlet segmentation, product category contribution, and operational insights.

---

## 2. Short Description / Purpose

The Blinkit Sales Dashboard is a multi-page analytical Power BI report designed to evaluate sales performance across outlet types, outlet sizes, and product categories.

This project helps uncover revenue trends, top-performing outlet segments, product distribution insights, and operational patterns to support data-driven retail decision-making.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

• 🗄 SQL – Data aggregation, KPI calculation, ranking, and validation  
• 📊 Power BI Desktop – Data visualization and dashboard creation  
• 🔄 Power Query – Data cleaning and transformation  
• 🧠 DAX (Data Analysis Expressions) – KPI measures such as Total Sales, Average Sales, and Rating metrics  
• 🔗 Data Modeling – Relationships between outlet, item, and sales tables  
• 📁 File Format – `.pbix` for development and `.png` for dashboard preview  

---

## 4. Data Source

Source: Blinkit Retail Sales Dataset  

The dataset includes transactional and outlet-level data such as:

- Outlet Type  
- Outlet Size  
- Outlet Location Tier  
- Item Type  
- Total Sales  
- Number of Items  
- Average Sales  
- Average Rating  
- Item Visibility  

This structured dataset enables segmentation analysis across multiple business dimensions.

---

## 5. Features / Highlights

### • Business Problem

Retail businesses generate large volumes of sales data, but raw datasets do not easily answer critical business questions such as:

- Which outlet types generate the highest revenue?  
- How does outlet size impact performance?  
- Which product categories contribute the most sales?  
- How does location tier affect revenue distribution?  
- What are the differences between Tier 1, Tier 2, and Tier 3 markets?  

Management requires structured dashboards to optimize expansion strategy, inventory allocation, and performance tracking.

---

### • Goal of the Dashboard

To develop an interactive retail performance dashboard that:

- Tracks overall sales KPIs  
- Segments performance by outlet type and size  
- Compares revenue across location tiers  
- Analyzes product category contribution  
- Identifies operational and strategic improvement areas

## • SQL Analysis Performed

- Aggregation of total sales using SUM()  
- Average sales calculation  
- GROUP BY analysis for outlet type and size  
- Tier-wise revenue segmentation  
- Category-level ranking  
- Validation of KPI measures before visualization in Power BI  

---

## • Business Impact & Insights

• Expansion Strategy: Tier 3 locations show strong revenue potential  
• Store Format Optimization: Medium-sized outlets generate the highest contribution  
• Product Strategy: Focus inventory on high-performing item categories  
• Performance Benchmarking: Compare outlet types for efficiency  
• Data-Driven Decision Making: Support pricing, stocking, and marketing strategies
